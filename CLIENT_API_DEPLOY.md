# 17. LIVE DEPLOYMENT VERIFICATION

```text
https://client-api.mybizgate.com/api/v1/health
```

Use cache busting:

```bash
curl -fsSL \
  -H "Cache-Control: no-cache" \
  -H "Pragma: no-cache" \
  "https://client-api.mybizgate.com/api/v1/health?nocache=${GITHUB_SHA}"
```

The response must contain:

```text
status = ok
service = MyBizGate Client API
environment = production
deployment.commit = current short GITHUB_SHA
```

Do not declare deployment successful merely because the FTP action succeeded.

The live application must report the current deployed commit.

---

# 18. RETRY LIVE VERIFICATION

Shared hosting may need a short period for FTP writes or PHP OPcache.

Retry safely.

Example:

```bash
EXPECTED="${GITHUB_SHA::8}"

for i in $(seq 1 12); do

  RESPONSE=$(curl -fsSL \
    -H "Cache-Control: no-cache" \
    "https://client-api.mybizgate.com/api/v1/health?nocache=${GITHUB_SHA}-${i}" \
    || true)

  echo "$RESPONSE"

  if echo "$RESPONSE" | grep -q '"status":"ok"' \
    && echo "$RESPONSE" | grep -q '"service":"MyBizGate Client API"' \
    && echo "$RESPONSE" | grep -q "\"commit\":\"$EXPECTED\""; then

      echo "Production deployment verified: $EXPECTED"
      exit 0
  fi

  sleep 10

done

echo "Production does not report expected commit: $EXPECTED"
exit 1
```

Do not wait excessively.

# 19. RECOMMENDED WORKFLOW

Implement approximately:

```yaml
name: Deploy Production

on:
  push:
    branches:
      - deploy
  workflow_dispatch:

concurrency:
  group: production-${{ github.repository }}
  cancel-in-progress: false

permissions:
  contents: read

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment: production

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup PHP 8.3
        uses: shivammathur/setup-php@v2
        with:
          php-version: '8.3'
          extensions: mbstring, xml, curl, zip, fileinfo, pdo, pdo_mysql, gd
          coverage: none

      - name: Validate Composer
        run: composer validate --no-check-publish

      - name: Install dependencies
        run: |
          composer install \
            --no-dev \
            --prefer-dist \
            --no-interaction \
            --no-progress \
            --optimize-autoloader

      - name: Prepare CI environment
        run: |
          cp .env.example .env
          php artisan key:generate

      - name: Validate Laravel
        run: |
          php artisan --version
          php artisan route:list
          php artisan test

      - name: Generate deployment identity
        run: |
          SHORT_SHA="${GITHUB_SHA::8}"
          DEPLOYED_AT="$(date -u +'%Y-%m-%dT%H:%M:%SZ')"

          cat > bootstrap/deployment.json <<EOF
          {
            "commit": "$SHORT_SHA",
            "deployed_at": "$DEPLOYED_AT"
          }
          EOF

          cat bootstrap/deployment.json

      - name: Prepare deployment package
        run: |
          mkdir -p deploy

          rsync -a ./ deploy/ \
            --exclude='.git/' \
            --exclude='.github/' \
            --exclude='deploy/' \
            --exclude='.env' \
            --exclude='.env.*' \
            --exclude='tests/' \
            --exclude='node_modules/' \
            --exclude='storage/logs/*' \
            --exclude='storage/framework/cache/data/*' \
            --exclude='storage/framework/sessions/*' \
            --exclude='storage/framework/views/*' \
            --exclude='bootstrap/cache/*.php'

          mkdir -p deploy/storage/logs
          mkdir -p deploy/storage/framework/cache/data
          mkdir -p deploy/storage/framework/sessions
          mkdir -p deploy/storage/framework/views
          mkdir -p deploy/bootstrap/cache

      - name: Verify deployment package
        run: |
          test -f deploy/artisan
          test -f deploy/composer.json
          test -f deploy/vendor/autoload.php
          test -f deploy/bootstrap/app.php
          test -f deploy/routes/api.php
          test -f deploy/bootstrap/deployment.json

          test ! -f deploy/.env
          test ! -f deploy/bootstrap/cache/config.php

          du -sh deploy

      - name: Deploy Laravel via FTPS
        uses: SamKirkland/FTP-Deploy-Action@v4.4.0
        with:
          server: ${{ secrets.FTP_SERVER }}
          username: ${{ secrets.FTP_USERNAME }}
          password: ${{ secrets.FTP_PASSWORD }}
          protocol: ftps
          port: 21
          local-dir: ./deploy/
          server-dir: app/client-api/
          dangerous-clean-slate: false
          exclude: |
            **/.git*
            **/.git*/**
            **/.env
            **/.env.*
            **/storage/logs/**
            **/storage/framework/cache/data/**
            **/storage/framework/sessions/**
            **/storage/framework/views/**
            **/bootstrap/cache/*.php

      - name: Verify live production
        run: |
          EXPECTED="${GITHUB_SHA::8}"

          for i in $(seq 1 12); do

            RESPONSE=$(curl -fsSL \
              -H "Cache-Control: no-cache" \
              -H "Pragma: no-cache" \
              "https://client-api.mybizgate.com/api/v1/health?nocache=${GITHUB_SHA}-${i}" \
              || true)

            echo "$RESPONSE"

            if echo "$RESPONSE" | grep -q '"status":"ok"' \
              && echo "$RESPONSE" | grep -q '"service":"MyBizGate Client API"' \
              && echo "$RESPONSE" | grep -q "\"commit\":\"$EXPECTED\""; then

              echo "Production verified at commit $EXPECTED"
              exit 0
            fi

            sleep 10
          done

          echo "Production does not report expected commit $EXPECTED"
          exit 1
```

Adapt safely to the actual project structure.
